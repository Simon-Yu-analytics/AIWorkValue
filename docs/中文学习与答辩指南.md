# 让 AIWorkValue 成为你能够讲清楚的研究项目

项目主线是“生成式 AI 在什么条件下值得企业投入”。它的成果是研究报告和可复现分析，展示实验设计、统计推断与商业判断。

你已有 Python、SQL 和基础机器学习经验。这次不需要训练大模型。需要补充的是前后测、随机分组、回归控制、置信区间，以及实验效果怎样转成有条件的商业预算。

## 第 1 周：理解数据和研究设计

读原论文的研究设计、作者 ReadMe 和本项目 DATA_AND_METHODS.md，运行 `make download`、`make run`。亲自检查从 786 条原始记录到 453 名保留参与者的每一步。

必须能回答：为什么 453、359、346、352 都是正确数字？任务 A 为什么不等于前测？为什么固定时长组不进入主要时间分析？原始数据中的实际使用者为什么不能被单独拿出来当随机实验的处理组？

产出：用自己的话画一张研究设计图，写下 3 条最重要的样本限制。

## 第 2 周：复现统计分析

逐格运行 notebook，先看描述统计，再运行时间和质量两个模型。理解 assignment 系数的单位：前者是分钟，后者是 1–7 分量表上的分数差，不要把 0.70 分随意写成质量准确率提高 70%。

运行 SQL 并核对分组人数。对比“只看后测”“看前后变化”“控制基线”三种估计，解释为什么数值接近但不会完全相同。

产出：一页方法说明和你亲自重跑的结果截图。能解释置信区间、HC3 的用途和两项主要检验的多重比较处理即可，不需要推导所有统计公式。

### SQL 练习：不是只会查询均值

先读 `sql/README.md` 和 `reports/SQL_Analysis.md`。已有 4 个入门查询和 10 个独立分析文件；`00_analysis_layer.sql` 建立公共视图与配置表。

建议按顺序亲自解释这些查询：

1. `01` 用 `LAG` 计算每一步排除多少记录，区分原始问卷记录和实验参与者。
2. `02` 用条件聚合核对有效时间配对与质量配对，解释为什么缺失值不能补成零。
3. `03` 用 CTE、自连接和样本方差比较保留样本的基线差异。理解标准化均值差不等于回归系数，也不消除流失偏差。
4. `04` 只在完整配对中计算前后变化，解释其与 Python 调整后估计的区别。
5. `07`、`08` 用 SQL 独立算净容量价值、最高可承受席位成本、复核时间上限和最低任务频率；找出哪些分母为零时应该返回 NULL。
6. `09` 用窗口函数观察每多一分钟复核，商业价值减少多少。3 个主情景和全部 36 个敏感性组合都要与 Python 对账。

面试里可以说：“SQL 负责样本诊断、描述比较和商业指标计算；Python 负责回归及稳健推断。我没有把未调整的前后变化当成主回归结果，也没有把缺失随访当成没有使用 AI。”这次 SQL 扩展是在主结果已知后补充的，不能称为新的预注册分析。

## 第 3 周：完成你自己的商业延伸

选择一个你熟悉的写作任务，例如短分析备忘录、项目进度邮件或营销文案草稿。列明它与原实验的相同点和不同点，尤其是事实核查、公司背景知识和协作要求。

修改 `Scenario` 中的任务频率、复核时间、成本或效果可迁移比例，重新生成敏感性结果。说明为何同一个实验的正向结果，在企业情景里可能产生负的净容量价值。

仓库已经实现一个具体扩展：`reports/extensions/Weekly_Status_Email.md` 比较每月 4、8、20 次适用写作任务，以及每次额外 1、3、5 分钟复核。先运行 `make extension` 并阅读对应 SQL，解释为什么每周只用一次即使省时间，也可能无法覆盖订阅成本。然后可以自己调整一个参数，观察结果；如果没有实际观测，应保留“假设”标记，不能编造企业访谈和收益。该计算已实现，不代表你已亲自完成邮件实验或掌握全部代码。

产出：一份新的情景配置、重建后的图，以及 500 字商业建议。

## 第 4 周：完成研究表达和答辩

用报告和 Executive Memo 练习 3–5 分钟英文介绍：商业问题、实验为什么有识别力、自己如何复现、主要结果、不能证明什么，以及企业下一步应该测什么。

## 面试常见问题

**为什么这是 AI 项目，却没有训练模型？** 研究问题是 AI 使用的商业效果。企业需要判断是否投入，而不仅是预测一个标签。这里展示如何使用随机实验数据评估技术的作用与边界。

**为什么不用机器学习预测谁最适合用 AI？** 这份样本较小，基线分数只是一项写作任务的表现，不能当作通用能力或真实员工决策依据。当前更可靠的贡献是估计平均效果、探索差异并设计新的试点。

**你是完全复现论文吗？** 不是。样本重建匹配 453 人，但主质量模型采用参与者平均配对评分，论文有更细的评分者设定。项目明确说明差异，并用评分者固定效应模型检查方向是否稳定。

**10.3 分钟节省意味着公司效率提高多少？** 不能直接回答。它是历史短写作任务中的可用样本分配效应。公司还需要估计任务占比、复核时间、迁移程度和成本；释放的工时也不自动等于现金节省。

**你最想进一步验证什么？** 在一个具体企业写作流程中测量“到可接受结果的总时间”，包括核实和返工，并检查正向结果是否在保守成本情景中仍成立。
